# docs/verlauf – gemeinsames Gedächtnis aller Claude-Sitzungen

Chats und Sessions sehen sich gegenseitig nicht (Cowork im privaten Account, Claude Code im unity-concepts-Account, weitere Chats im claude.ai-Projekt). Was alle teilen, ist **dieser Ordner im Repo**.

- `00-projektuebersicht.md` – Links, Accounts, Struktur, Stand, Regeln
- `01-verlauf-konzept-chat.md` – Konzept-Chat (Cowork), 02.–16.11.2026
- `NN-verlauf-<quelle>-<thema>.md` – je Chat/Session eine eigene Datei (z. B. `02-verlauf-claude-code-umsetzung.md`)

Regeln:
- Jede Sitzung schreibt nur ihre **eigene** Verlaufsdatei; fachliche Entscheidungen zusätzlich in `docs/entscheidungen.md`, `docs/design.md`, `docs/backlog.md`.
- Am Ende eines Arbeitsschritts kurz ergänzen: was entschieden wurde, welches Feedback JPO gegeben hat, was offen ist.
- Die Dateien werden ins claude.ai-Projekt „city concepts Landingpages“ gespiegelt (Ordner `claude/` bzw. `repo/`). Führend ist immer das Repo.
